# Third-party components

Retro Portal integrates with upstream projects that keep their own licenses, trademarks and copyright terms.

- **EmulatorJS** — browser emulation frontend/runtime: https://emulatorjs.org/ · source: https://github.com/EmulatorJS/EmulatorJS
- **RetroArch / libretro cores** — emulation cores bundled by EmulatorJS retain their individual licenses: https://www.libretro.com/ · https://github.com/libretro
- **Nginx** — web server and reverse proxy: https://nginx.org/
- **Docker Engine / Compose** — container runtime: https://docs.docker.com/engine/
- **Certbot** — Let's Encrypt automation: https://certbot.eff.org/
- **certbot-dns-cloudflare** — Cloudflare DNS-01 plugin: https://certbot-dns-cloudflare.readthedocs.io/
- **TheGamesDB** — optional game metadata and box-art provider: https://thegamesdb.net/
- **MediaWiki API / Wikipedia** — optional historical context proposals: https://www.mediawiki.org/wiki/API:Main_page
- **retro-homebrew-games** — redistributable homebrew ROMs used by the public demo where applicable: https://github.com/monteslu/retro-homebrew-games

The Retro Portal repository does **not** distribute commercial ROMs, proprietary BIOS images or official commercial game artwork.

See each upstream project for its exact license and redistribution terms. The MIT license in this repository applies only to Retro Portal code that is covered by `LICENSE`.
