# Roadmap

## Near term

- curated library tooling for user-supplied Mega Drive / PS1 content;
- cloud saves and accounts;
- richer metadata and platform shelves;
- verified Flycast WASM integration for Dreamcast;
- optional achievements and netplay experiments.

## Non-goals

Retro Portal will not distribute commercial ROMs, console BIOS files or copyrighted official artwork.
