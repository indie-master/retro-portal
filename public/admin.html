Игроки просто играют.

ROM и BIOS настраиваются здесь. Публичный портал показывает только те игры, которые уже полностью готовы к запуску.

Токен хранится только в sessionStorage текущей вкладки.

ДОБАВИТЬ ИГРУ

Загрузить ROM

01

Выберите ROM. Для однозначных форматов консоль определится сама. Для CHD/BIN/CUE укажите платформу.

ЗАВИСИМОСТИ

Загрузить BIOS

02

Менеджер покажет BIOS только там, где он действительно нужен. Для известных PS1 BIOS имя определяется по MD5 автоматически.

ЕСЛИ ROM УЖЕ СКОПИРОВАНЫ НА СЕРВЕР

Сканирование папок

Можно загружать большие образы через SCP/SFTP в games/roms/<platform>/, затем нажать «Сканировать». Новые игры автоматически появятся в каталоге.
