# Мобильная игра

Retro Portal поддерживает мобильные браузеры для систем, которые запускаются через EmulatorJS. Игра начинает загружаться сразу после открытия страницы — отдельного мобильного экрана запуска нет.

Чтобы развернуть игровое поле, нажмите **ПОЛНЫЙ ЭКРАН**. Портал запросит системный fullscreen и, если браузер разрешает, зафиксирует landscape-ориентацию. Если системный fullscreen недоступен, используется чистый полноэкранный режим страницы; выйти из него можно той же кнопкой.

На сенсорных устройствах EmulatorJS показывает виртуальный геймпад. Для PlayStation используется отдельная раскладка с крестовиной, △/○/✕/□, L1/L2, R1/R2, Start и Select.

PlayStation значительно требовательнее 8/16-битных систем. На мобильных устройствах портал загружает CHD/PBP последовательными HTTP-диапазонами по 8 МиБ прямо в файловую систему эмулятора. Это исключает вторую полноразмерную копию образа в JavaScript-памяти, из-за которой iPhone Safari мог перезапускать страницу ближе к концу загрузки. Внутренний кэш ROM и потоки для мобильной PS1 отключены.

Для PS1 используйте CHD или PBP. Потоковая загрузка намеренно не применяется к BIN/ISO и архивам: предварительно преобразуйте такие образы в CHD/PBP. Сервер должен отдавать `Content-Length`, `Accept-Ranges: bytes` и корректные ответы `206 Content-Range`; штатный Nginx Retro Portal уже настроен соответствующим образом.

Fullscreen и orientation lock требуют пользовательского жеста. Если ориентация не зафиксировалась, поверните устройство вручную.
