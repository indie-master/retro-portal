# Мобильная игра

Retro Portal поддерживает мобильные браузеры для систем, которые запускаются через EmulatorJS. На телефоне или планшете откройте игру, поверните устройство в альбомную ориентацию и нажмите **МОБИЛЬНЫЙ РЕЖИМ**. До этого нажатия ROM не скачивается.

Портал запросит системный fullscreen и, если браузер разрешает, зафиксирует landscape-ориентацию. В iPhone/iPad Safari, где fullscreen для обычного HTML-элемента может быть недоступен, автоматически используется полноэкранный слой поверх страницы. Кнопка **ВЫЙТИ** в верхней части игрового поля возвращает обычную страницу.

На сенсорных устройствах EmulatorJS показывает виртуальный геймпад. В мобильном режиме Retro Portal убирает второстепенные панели, растягивает игровую область на фактически доступную высоту браузера, учитывает safe-area на устройствах с вырезами и блокирует прокрутку внутри игрового поля. Для PlayStation используется отдельная раскладка с крестовиной, △/○/✕/□, L1/L2, R1/R2, Start и Select.

PlayStation значительно требовательнее 8/16-битных систем. На мобильных устройствах портал отключает потоки и сохранение большого образа во внутренний кэш EmulatorJS, чтобы не держать лишнюю копию ROM в памяти. Для PS1 используйте CHD или PBP; BIN/ISO заметно тяжелее для мобильного браузера.

Fullscreen и orientation lock требуют пользовательского жеста. Если ориентация не зафиксировалась, поверните устройство вручную; полноэкранный слой продолжит работать.
